# Deployment Instructions for Docker Compose

## Overview
This project uses Docker Compose to manage a MySQL database and a Python-based application. Below are the steps to build, run, and manage the containers.

## Prerequisites
Before proceeding, ensure that you have the following installed:
- [Docker](https://www.docker.com/get-started)

## Setup Instructions

### 1. Clone the Repository
```sh
docker-compose up
```
