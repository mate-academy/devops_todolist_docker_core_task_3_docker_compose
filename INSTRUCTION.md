Проєкт запускається за допомогою Docker Compose і складається з Todolist-застосунку та MySQL бази даних.
Todos зберігаються в MySQL з підключеним persistent volume, тому дані не втрачаються після перезапуску контейнерів.

Перед запуском необхідно мати встановлені Docker та Docker Compose.
Потрібно перейти в корінь проєкту.
Для запуску контейнерів виконується команда docker-compose up.
Під час старту контейнера автоматично виконуються міграції бази даних і запуск застосунку.
Після успішного запуску застосунок готовий до роботи.

Для зупинки контейнерів використовується команда docker-compose down.
Після зупинки всі дані в базі даних зберігаються у volume.

Збірка образу не залежить від доступності бази даних.
