# Інструкція по запуску ToDo App через Docker Compose

## 📦 Склад проєкту

Цей проєкт складається з двох сервісів:

- **MySQL** — база даних, у якій зберігаються завдання (todo).
- **Django ToDo App** — веб-додаток, що дозволяє створювати та переглядати завдання.

## ⚙️ Попередні вимоги

- Встановлений Docker
- Встановлений Docker Compose
