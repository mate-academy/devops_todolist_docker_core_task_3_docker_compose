# Інструкція із запуску Django-Todolist за допомогою Docker Compose

Ця інструкція пояснює, як запустити веб-застосунок Django-Todolist разом з базою даних MySQL за допомогою Docker Compose.

## Передумови

- [Docker](https://www.docker.com/get-started)
- [Docker Compose](https://docs.docker.com/compose/install/)

## Запуск контейнерів

1.  Переконайтеся, що ви знаходитесь у кореневому каталозі репозиторію, де розташований файл `docker-compose.yml`. 
2.  Щоб зупинити роботу додатку, натисніть `Ctrl+C` у терміналі, де ви запускали `docker-compose up`.
3.  Виконайте команду, щоб побудувати образи та запустити контейнери:

    ```bash
    docker-compose up -d --build
    ```

    * `-d`: Запускає контейнери у фоновому режимі.
    * `--build`: Побудує образи перед запуском, якщо вони ще не були побудовані або якщо були внесені зміни до `Dockerfile` або файлу `docker-compose.yml`.

3.  Після того, як контейнери запустяться, Django-застосунок буде доступний за адресою `http://localhost:8000` у вашому веб-браузері.

4.  API можна переглянути за адресою `http://localhost:8000/api/`.

## Зупинка контейнерів

1.  Переконайтеся, що ви знаходитесь у кореневому каталозі репозиторію. 

2.  Щоб зупинити роботу додатку, натисніть `Ctrl+C` у терміналі, де ви запускали `docker-compose up`.

3.  Виконайте команду, щоб зупинити та видалити запущені контейнери:

    ```bash
    docker-compose down
    ```

    * Ця команда зупинить сервіси, запущені командою `up`, і видалить створені контейнери та мережі.

3.  Якщо ви також хочете видалити томи, включаючи дані бази даних MySQL (якщо вони більше не потрібні), ви можете додати опцію `-v`:

    ```bash
    docker-compose down -v
    ```

## Додатково

* Щоб переглянути журнали контейнерів, використовуйте команду:
    ```bash
    docker-compose logs -f <назва_сервісу>
    ```
    Наприклад, щоб переглянути журнали Django-застосунку:
    ```bash
    docker-compose logs -f app
    ```
    Або для бази даних MySQL:
    ```bash
    docker-compose logs -f db
    ```

* Щоб виконати команди всередині контейнера, використовуйте команду `docker exec -it <назва_сервісу> bash`. Наприклад, щоб зайти в shell контейнера Django-застосунку:
    ```bash
    docker exec -it app bash
    ```
