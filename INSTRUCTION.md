## Prerequisites:
1. The following must be installed on the computer Docker Desktop.
2. Download the project repository.

## To start:
1. Go to the project folder.
2. To run the program, enter the following command: 
```docker-compose up --build```

## To check:
To view the service, go to  http://localhost:8080/

## To stop the service,use: 
```docker-compose down```
