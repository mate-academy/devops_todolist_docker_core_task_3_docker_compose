## Running the Application Stack

```bash
docker compose up -d
```
## Verification and Access
### Check Service Status:

```bash
docker compose ps
```
### Check Logs 
```bash
docker compose logs -f app
```
### Access via Browser:

http://localhost:8080 (or http://127.0.0.1:8080)

## Stopping Up
```bash
docker compose stop
```
