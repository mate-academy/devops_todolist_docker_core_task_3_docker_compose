# MySQL and TodoApp Docker Setup Guide

## 1. Running Containers
```bash
git clone https://github.com/TarasSavchyn/devops_todolist_docker_core_task_3_docker_compose.git
cd devops_todolist_docker_core_task_3_docker_compose
```

```bash
docker-compose up --build
```

## 2. Accessing the Application
```bash
http://localhost:8080
```

## 3. Stop container

```bash
docker-compose down
```
