📖 Інструкція з розгортання ToDoApp у Docker

🚀 1. Встановлення необхідних інструментів
✔️Перед початком роботи переконайтеся, що у вас встановлено: Docker, Docker Compose.

📂 2. Клонування репозиторію
✔️Форкніть та склонуйте даний репозиторій, для клонування виконайте команду git clone <посилання з репозиторію> та відкрийте у кодовому редакторі

⚙️ 3. Налаштування середовища
✔️Створіть .env файл і вкажіть змінні середовища:
- MYSQL_ROOT_PASSWORD=****
- MYSQL_DATABASE=db_name
- MYSQL_USER=app_username
- MYSQL_PASSWORD=****
- APP_ENV=Development
- PYTHONUNBUFFERED=1

🏗️ 4. Білд та запуск контейнерів
✔️Виконайте команду: docker-compose up --build -d
✔️Що відбувається?
- Білдяться образи для MySQL та PythonApp.
- Контейнери запускаються у фоновому режимі (-d).

🔍 5. Перевірка роботи
✔️Переконайтеся, що контейнери працюють: docker ps
✔️Якщо все добре, веб-застосунок буде доступний за адресою:
👉 http://localhost:8080

🛑 6. Зупинка та видалення контейнерів
✔️Якщо потрібно зупинити всі контейнери: docker-compose down
✔️Щоб повністю очистити дані БД (необоротно!): docker-compose down -v

🔥 Додаткові команди
📜 Перегляд логів: docker-compose logs -f
🐳 Перезапуск контейнерів: docker-compose restart
📦 Запуск окремого контейнера (наприклад, бази даних): docker-compose up -d mysql

✅ Готово! Тепер Ви можете використовувати ToDoApp 🚀
